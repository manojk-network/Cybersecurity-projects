
# OWASP ZAP Web Application Security Testing
## Project Overview

- This project demonstrates how to use OWASP ZAP (Zed Attack Proxy) to perform basic web application security testing. The goal is to identify common web application vulnerabilities and understand how security testing works in a safe and authorized environment.

## Objectives
- Learn the basics of OWASP ZAP.
- Scan a web application for security vulnerabilities.
- Analyze scan results.
- Understand common web application security issues.
- Practice basic vulnerability assessment.

## Tools Used
- OWASP ZAP
- Web Browser
- Test Web Application

## Features
- Automated web application scan
- Passive and active scanning
- Vulnerability detection
- Security alerts and reports
- Basic security analysis

## Project Workflow
- Install and configure OWASP ZAP.
- Launch the target web application.
- Configure the browser to use ZAP as a proxy.
- Perform passive and active scans.
- Review identified vulnerabilities.
- Analyze findings and generate a report.
- Skills Learned
- Web Application Security Testing
- Vulnerability Assessment
- Security Scanning
- OWASP ZAP Configuration
- Report Analysis
- Ethical Hacking Fundamentals
