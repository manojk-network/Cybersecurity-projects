# 🔐 Gobuster Web Enumeration
## 📌 Project Overview

This project demonstrates the use of Gobuster, a popular cybersecurity tool used for directory and file enumeration during web security testing.

Gobuster helps discover hidden directories, files, and resources on a web server.

## 🛠️ Tools Used
- Gobuster – Web Enumeration Tool
- Kali Linux – Cybersecurity Testing Environment
  
## 🎯 Objectives
- Understand what Gobuster is
- Learn directory and file enumeration
- Discover hidden web directories
- Analyze HTTP status codes
- Practice web reconnaissance
- Understand basic web security testing
  
## 🔍 Basic Command
```
gobuster dir -u <target> -w <wordlist>
```
Example:
```
gobuster dir -u http://example.com -w /usr/share/wordlists/dirb/common.txt
```
## 🔎 What Gobuster Can Discover
- Hidden directories
- Web files
- Backup files
- Common web resources
- Accessible endpoints
  
## 📚 What I Learned

Through this project, I learned about:

- Web reconnaissance

- Identifying accessible web resources
- Basic penetration testing techniques
