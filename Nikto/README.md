# 🔐 Nikto Web Server Security Scanning
## 📌 Project Overview

This project demonstrates the use of Nikto, an open-source web server scanner used for security testing and vulnerability assessment.

Nikto helps identify potential security issues such as outdated server software, insecure configurations, dangerous files, and known vulnerabilities.

## 🛠️ Tools Used
Nikto – Web Server Security Scanner
Kali Linux – Cybersecurity Testing Environment

## 🎯 Objectives
- Understand what Nikto is
- Perform a basic web server security scan
- Identify potential security issues
- Analyze Nikto scan results
- Practice web security testing in a controlled environment

## 🔍 Basic Command
```
nikto -h <target>
```
Example:
`
nikto -h http://example.com
`
## 🔎 What Nikto Can Detect
- Outdated server software
- Security misconfigurations
- Potentially dangerous files
- Known vulnerabilities
- Interesting HTTP headers
- Common web server issues

## 📚 What I Learned

Through this project, I learned about:

- Web server reconnaissance
- Vulnerability scanning
- HTTP response analysis
- Security misconfiguration detection
- Basic web security testing
